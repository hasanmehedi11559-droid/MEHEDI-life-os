Admission Tracker V7

Community V7 UI/account foundation is included.
Required for production real-time cross-device operation:
- Secure backend authentication (mobile + password; password hashing server-side)
- Database for accounts, groups, messages, reactions, replies and announcements
- Object storage for images/PDF/audio/video/files
- Realtime messaging/subscriptions
- Push notification service

No owner/admin password is hard-coded in this source package.
