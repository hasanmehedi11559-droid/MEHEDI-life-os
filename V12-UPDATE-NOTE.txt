PI EduTrack V12 — Online Community / Mobile + Password patch

- True Supabase Realtime community remains the backend for shared Boys/Girls group chat.
- Community account login now uses Mobile Number + Password without SMS/OTP.
- Supabase Auth still securely hashes and manages passwords; the app never stores raw passwords.
- The mobile number is stored in the student profile; an internal deterministic email identity is used only for Supabase Auth.
- Supabase Email Confirmation must be OFF for this no-SMS mode, otherwise newly created accounts will not receive a session.
- Supabase Project URL + publishable key are configured in supabase-config.js.
- Never put a Supabase secret/service_role key in the PWA.
- Service-worker cache bumped so installed users can receive this update.
